# Política de Privacidade — DJ Cleiton Rasta

O DJ Cleiton Rasta é um bot de Discord pessoal.

## Dados do Google

O bot usa a Google Meet REST API com o escopo `meetings.space.created` somente para criar salas
do Google Meet quando alguém usa o comando `/live`. O bot:

- não lê, guarda nem compartilha e-mails, contatos, agenda ou qualquer outro dado da conta Google;
- não guarda as salas criadas, apenas envia o link no canal do Discord;
- não vende nem repassa dados a terceiros.

## Dados do Discord

O bot só processa os comandos enviados a ele. O histórico de músicas (`/history`) fica apenas
na memória e é apagado quando o bot reinicia.
